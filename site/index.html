Seus segredos, trancados de verdade.

Tudo que o Memo faz

Um cofre completo, mas sem nada rodando na nuvem.

🔒

Criptografia forte

AES-256-GCM (cifra autenticada) com chave derivada por PBKDF2-SHA256, 200.000 iterações. Cada segredo é um arquivo cifrado.

🗂️

Um arquivo por segredo

Modelo file-based: guarde o cofre numa pasta sincronizada (ex.: OneDrive) e tenha seus segredos em qualquer PC. Sem banco central.

🏠

100% local

Sem servidores, sem telemetria, sem cadastro. Seus dados ficam só na sua máquina (e no seu backup).

⚡

Busca instantânea

Encontre qualquer segredo digitando. Enter copia o valor direto para a área de transferência.

🧰

GUI + CLI scriptável

Interface para o dia a dia e o memo-cli para automação: saída no stdout, --json, --bytes e exit codes.

🎲

Gerador de senha & GUID

Gere senhas fortes pelas suas regras (tamanho e tipos de caractere) e UUIDs — copiados na hora, ou salvos direto no cofre.

⏰

Lembretes

Em linguagem natural (9h tomorrow, every 30 minutes). O app avisa pela bandeja, com opção de adiar.

⏱️

Sessão & bloqueio

Depois de destrancado, o cofre fica acessível por uma janela curta e configurável. Um clique no cadeado tranca na hora.

🎨

Temas & auto-update

Tema claro ou escuro trocado em runtime. E o app verifica novas versões no GitHub, valida por SHA256 e atualiza com um clique.

Lembretes em linguagem natural

Diga o que lembrar e quando, do seu jeito — em português ou inglês. O Memo interpreta a data/hora, guarda o lembrete e avisa pela bandeja no momento certo, com som e um popup. Lembrete não é segredo: não pede a senha-mestra.

  • Hora do dia: 10:00, 22h, amanhã 9:30.
  • Relativo: in 15 minutes, daqui a 2 horas.
  • Recorrente: every 30 minutes, a cada 2 horas.
  • No aviso, dá para concluir ou adiar (soneca).

Feito para automação

O memo-cli cospe o resultado no stdout — pipes, scripts e exit codes.

PowerShell / bash
# destranca uma vez; a sessão vale para os próximos
memo-cli unlock --password "$MEMO_PW"

# lê um segredo (stdout) e usa em outro comando
$token = memo-cli get "github token" --text

# grava a partir de um pipe, sem deixar rastro
echo -n $senha | memo-cli set "api key" --stdin

# lista em JSON para processar
memo-cli list --json

Comandos

  • get · set · list · del
  • pass · guid · remember
  • unlock · lock · migrar
  • config --dir · version · help
  • Saída --text · --json · --bytes · --copy.
  • Senha via --password ou MEMO_PASSWORD.
  • Pasta do cofre via MEMO_DIR ou config --dir.
  • Exit codes: 0 ok · 2 trancado · 3 não encontrado.

Como funciona

1

Crie seu cofre

No primeiro uso, escolha a pasta e defina uma senha-mestra. Ela protege todos os documentos e não pode ser recuperada se esquecida.

2

Guarde seus segredos

Adicione chaves e valores pela interface ou pela linha de comando. Cada item vira um arquivo criptografado.

3

Acesse quando precisar

Busque, copie e edite com um clique. Pela CLI: memo-cli get "github token" já devolve o valor.

Segurança em primeiro lugar

O Memo foi desenhado para que seus dados sejam inúteis para qualquer um sem a senha-mestra. A senha nunca é gravada em disco — apenas a chave de sessão temporária, protegida pela DPAPI do Windows (vinculada à sua conta de usuário).

  • Cifragem autenticada AES-256-GCM (detecta adulteração).
  • Derivação de chave PBKDF2-SHA256 com 200.000 iterações.
  • Sessão isolada por cofre e validada contra o cofre atual.
  • Chaves sanitizadas contra path traversal (/, \, ..).
  • Comandos memo set apagados do histórico do Win+R.
  • Atualização verificada por SHA256 antes de trocar o executável.
PowerShell
# copia um segredo para a área de transferência
memo get "github token"

# cria ou atualiza um segredo
memo set "chave pix" = a1b2c3d4

# gera uma senha e salva no cofre
memo pass "wifi casa"

# abre a interface gráfica
memo
